# GB10 (DGX Spark, aarch64, compute capability 12.1) build.
# Replaces requirements/cuda.txt's torch/flashinfer pins with real wheel
# dependencies from personal GitHub Releases, since no official aarch64/sm_121
# wheels exist upstream yet. Modeled on requirements/xpu.txt's own
# `@ URL` GitHub-Release-wheel pattern (vllm_xpu_kernels).
#
# flash-attention is NOT listed here -- it's consumed via CMake at build time
# (see cmake/external_projects/vllm_flash_attn.cmake, VLLM_FLASH_ATTN_PREBUILT_PKG
# path) rather than as a normal pip dependency, since vLLM's own
# vllm.vllm_flash_attn package nests the compiled extension as a sibling file
# via a relative import (`from . import _vllm_fa2_C`) that a top-level pip
# package can't satisfy directly. tuned/build.sh gb10 installs it explicitly before
# the vLLM build so the CMake step can find it via `import vllm_flash_attn`.

# FlashInfer should be updated together with the Dockerfile
# zbrad/flashinfer's tuned-builds branch (renamed from gb10-only, then
# native-builds), scoped
# to the shapes its release notes list (NemotronH incl. the NVFP4 stand-in's
# xqa and trtllm_utils; DeepSeek-V4-Flash) -- see that release's notes for the
# exact op set. flashinfer-jit-cache (NOT flashinfer-cubin -- a
# different, AOT-compiled-kernel packaging mechanism that this fork uses
# instead) supplies the actual GB10 binary; flashinfer-python alone has no
# compiled extension. Since flashinfer 0.7.2.post1 the jit-cache is two wheels:
# flashinfer-jit-cache is a shim with no binaries, and flashinfer-jit-cache-sm121a
# holds the compiled modules (found through the flashinfer.jit_cache.providers entry
# point). The shim requires the provider at its own exact version and the provider is
# not on PyPI, so both are pinned by URL. All three wheels share the same +gb10
# version, so the FLASHINFER_DISABLE_VERSION_CHECK workaround this file previously
# needed is no longer required. The packaged vllm wheel defaults FLASHINFER_DISABLE_JIT=1 at
# import (vllm/env_override.py, flag baked in by tuned/package.sh), to get a hard
# fail instead of a silent JIT compile for any op outside the filtered set.
flashinfer-python @ https://github.com/zbrad/flashinfer/releases/download/v0.7.2.post1%2Bgb10.cu134.20261102.0/flashinfer_python-0.7.2.post1%2Bgb10.cu134.20261102.0-py3-none-any.whl
flashinfer-jit-cache @ https://github.com/zbrad/flashinfer/releases/download/v0.7.2.post1%2Bgb10.cu134.20261102.0/flashinfer_jit_cache-0.7.2.post1%2Bgb10.cu134.20261102.0-py3-none-any.whl
flashinfer-jit-cache-sm121a @ https://github.com/zbrad/flashinfer/releases/download/v0.7.2.post1%2Bgb10.cu134.20261102.0/flashinfer_jit_cache_sm121a-0.7.2.post1%2Bgb10.cu134.20261102.0-cp39-abi3-linux_aarch64.whl
